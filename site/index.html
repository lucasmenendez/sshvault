Inside the app

A closer look at what you can do.

Everything is organized around the files you already know. Open the app, pick a key, host or file, and see what is deployed without digging through ~/.ssh by hand.

01 / Keys

Your keys stay yours.

Import the keys you already use or generate a new pair. Give each one a name and tags, check its fingerprint, and deploy it only when you decide to.

  • Public, private and certificate fields in one place
  • ed25519, RSA and ECDSA key generation
  • Copy, edit, deploy and remove local copies

02 / Hosts

A config you can read.

sshvault keeps the hosts it manages in a marked block at the top of ~/.ssh/config. You can see the hostname, user, port, identity files and advanced options while the rest of the file stays untouched.

  • Multiple identity files for the same host
  • Ordered advanced SSH options
  • Warnings when the same host is defined somewhere else

03 / Files

The rest of ~/.ssh.

Keep known_hosts, authorized_keys and other files in the same vault. Sensitive files get a clear warning, and local changes appear before anything gets overwritten.

  • Text and binary files with permissions
  • Warnings for files that control access
  • Deploy, download and local drift checks

04 / Vault

Locked when you are not using it.

The app starts locked and asks for the password in the window. When you step away, it discards the derived key and asks again on your next visit. You can also switch to another vault or create a new one from the lock screen.

  • Idle lock with a configurable timeout
  • Open an existing vault or start a new one
  • A portable encrypted file you control

Get started

Install in seconds.

Pick the command line or the app. Both use the same local vault, and everything stays on your Mac.

Command line

Homebrew formula for the local server and native UI.

brew tap lucasmenendez/sshvault
brew trust lucasmenendez/sshvault
brew install sshvault
Read the installation notes

macOS app

A self-contained SSHVault.app with its own binary and icon.

brew install --cask lucasmenendez/sshvault/sshvault-app
App installation notes

Ad-hoc signed, not notarized. If macOS blocks the first launch, use Privacy & Security → Open Anyway.

From source

Build the CLI or a local app with Go 1.27+.

git clone https://github.com/lucasmenendez/sshvault.git
cd sshvault
make build
make app
Development notes

Local by design

Your keys never leave the machine.

The web UI only listens on your machine. Host, Origin and CSRF checks protect the local session. The vault is encrypted with Argon2id and XChaCha20-Poly1305, and the password is never stored on disk.

  • 01Single encrypted, portable vault
  • 02OS-native file permissions and atomic writes
  • 03Idle lock discards the derived key
  • 04No telemetry, no external assets, no CDN
  • 05AGPL-3.0-only source available on GitHub

For people who like their SSH material close, where they can see it.
