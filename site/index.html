A complete SSH workspace

Everything in ~/.ssh, under control.

Review, edit, generate and deploy without losing track of what lives inside the vault and what is projected to disk.

Keys and certificates

Import existing keys, generate ed25519, RSA or ECDSA pairs, inspect fingerprints and deploy or remove local copies.

Hosts and config

Manage a marked block in ~/.ssh/config, multiple IdentityFiles, advanced options and duplicate host warnings.

Other files

Keep known_hosts, authorized_keys and other files in the same vault with download, deploy and drift checks.

Import and review

Scan ~/.ssh safely, preview everything first and apply imports only when you confirm.

Locked by default

The app starts locked, asks for the password in the UI and discards the derived key when idle.

Native app

Install the CLI or the self-contained macOS app. Both use the same local server and encrypted vault.

Inside the app

Designed to stay out of the way.

Native tables, a fixed workspace and focused forms for the things you actually change.

Get started

Install in seconds.

Use Homebrew for the command, the app, or both. Everything stays on your Mac.

Command line

Homebrew formula for the local server and native UI.

brew tap lucasmenendez/sshvault
brew trust lucasmenendez/sshvault
brew install sshvault
Read the installation notes

macOS app

A self-contained SSHVault.app with its own binary and icon.

brew install --cask lucasmenendez/sshvault/sshvault-app
App installation notes

Ad-hoc signed, not notarized. If macOS blocks the first launch, use Privacy & Security → Open Anyway.

From source

Build the CLI or a local app with Go 1.27+.

git clone https://github.com/lucasmenendez/sshvault.git
cd sshvault
make build
make app
Development notes

Local by design

Your keys never leave the machine.

The web UI binds to loopback only. Host, Origin and CSRF checks protect the local session. The vault is encrypted with Argon2id and XChaCha20-Poly1305, and the password is never stored on disk.

  • 01Single encrypted, portable vault
  • 02OS-native file permissions and atomic writes
  • 03Idle lock discards the derived key
  • 04No telemetry, no external assets, no CDN
  • 05AGPL-3.0-only source available on GitHub

Designed for people who keep their SSH material close.
